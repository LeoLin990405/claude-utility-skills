# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-03-16

### Added

- **skill-creator** -- End-to-end skill creation guide with scaffolding, packaging, and validation scripts.
- **mcp-builder** -- MCP server building skill with Python/Node.js references, best practices, and evaluation framework.
- **anthropic-docs** -- Anthropic documentation knowledge base covering API, models, Claude Code, research, and safety.
- **webapp-testing** -- Playwright-based web app testing skill with example scripts.
- **internal-comms** -- Internal communications templates for newsletters, updates, FAQs, and incidents.
- **history-note-processor** -- Deep reading and research note processing workflow.
- Repository scaffolding: README, SKILL.md, LICENSE (MIT), Claude Code review workflow.
- Issue templates (bug report, feature request) and PR template.
- CONTRIBUTING.md with skill submission guidelines.
